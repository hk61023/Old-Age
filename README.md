# 知年 · 养老金测算本地版

中文养老金测算网站。个人资料与CSV在浏览器中处理，政策与审核记录保存在本机SQLite中。

## 启动

已安装依赖并生成构建。双击根目录 `start.cmd`，或在PowerShell中执行：

```powershell
cd C:\codex\yanglao
npm start
```

访问 http://127.0.0.1:3210 。管理页为 http://127.0.0.1:3210/admin ，首次由你设置至少12位管理密码。关闭服务用终端中的 Ctrl+C。默认只监听本机，不开放局域网。

从源码重新安装、检查与构建：

```powershell
npm ci --cache .npm-cache
npm test
npm run build
npm start
```

要求Node.js 22.13以上，推荐本轮验证使用的22.14。使用Node内置SQLite，不需要额外安装数据库。Node22会显示SQLite实验性提示，不影响本轮启动和测试。`npm run dev`同样启动后端，修改前端后执行构建并刷新页面；修改后端后重启服务。

## 使用

1. 页面最初显示明确标注的示例资料；修改出生年月、适用退休类别、累计实际缴费月数和地区即可联动测算。红色星号表示必填，缴费时间只输入累计月份。
2. 补充截止月账户余额、经办核定缴费指数和首次参保年月，替换粗略历史假设。余额只从对应月份起衔接，不重复累加此前本金。
   账户金额指养老保险个人账户累计储存额（含已记账利息）。上年末余额应选择上年12月；本年余额选择权益记录的实际统计月份，未到的本年末预测值不作为实际余额。系统提供日期快捷项。
   退休结果分别显示原法定基础年龄、按出生年月增加的延迟月数和调整后法定年龄。个人官方平均缴费指数不能按地区统一预填；按参保地区自动匹配的是已核验的年度参考工资分母。
3. 在缴费记录中下载CSV模板、导入预览后确认。模板位于 `public/缴费记录模板.csv`。断缴月份不要填入，汇总和完整记录冲突时必须选择采用方式。
4. 比较最多三个缴费、退休及增长假设方案。默认基数年增长和未来账户利率均为0%，金额为退休首月名义金额。
5. 主动保存后才写入本浏览器localStorage。我的方案支持查看原结果、按当前发布政策重新计算、导出和逐项删除；最多保存30份。清除站点浏览器数据也会删除本机方案。SQLite备份不包括浏览器方案。

女性类别不能仅凭性别或灵活就业身份推断，应按岗位、参保身份、历史经历和当地规定核实原法定50岁或55岁类别。不确定时选择“不确定”，网站暂停金额计算。

## 首版覆盖与交付边界

已提供测算、结果、方案对比、政策资料库、本机方案与独立管理页面；大陆31省级行政区及其市/区可选。规则按月份处理延迟退休、最低缴费年限、弹性退休和跨省领取地情景。

北京、上海、浙江的普通职工模型及广东、深圳的已知组成已接入，保留2025年及上海新旧办法参数。浙江2026年参数、上海2026年新办法和广东2026年缴费上下限已核对官方发布。**尚不能将四地所有人群和历史项目标为完整核验**：广东地方加发与年限津贴需经办核定值，深圳地方补充项目保留缺口；早期历史指数和特殊人群不自动推断。北京、广东、深圳养老金计发基数仍以已核对的2025年度参数预测，并显式标注年份。

缺少关键组成时返回null并显示部分结果，不把缺失金额当0。浙江目前杭州普通公式含独立核对的年限取整与合计进角，其他浙江城市仅展示省级公式的部分结果，等待当地取整和地方项目核验。未来缴费按当前参保地区参考上下限；不同省份的未来指数换算、非整岁计发月数（上海以外）等尚未完整核验时列为情景假设。尚未接入地区不会套用其他地区参数。

政策更新发现机制已实现。部分政府站点在当前Node网络环境下有TLS、超时或访问限制，自动检查会记录失败并保留已发布版本；管理员可以从官方浏览器原文人工核验。抓取文字不会作为可执行公式。

## 代码与接口

- `src/core/engine.ts`：独立TypeScript计算模块，引擎版本1.0.2。
- `src/data/policies.ts`：官方来源、参数和适用区间种子；第一次启动写入数据库，已有数据库不会因修改种子而被覆盖。
- `src/ui/`：React页面；`src/core/csv.ts`：浏览器解析与校验。
- `server/`：Fastify、SQLite、管理员会话、候选审核和检查调度。
- `tests/`：计算及后台回归；`scripts/qa-server.ts`：独立内存数据库验收服务，仅记录HTTP方法/路径。

公共GET接口：`/api/health`、`/api/regions`、`/api/policies`、`/api/policies/:id/versions`。管理员接口在 `/api/admin/` 下，除了初始化、登录和状态外均需会话，写操作还需Origin及CSRF校验。后端没有个人养老金计算或缴费文件上传接口。

首版不含居民养老、机关事业单位待遇、商业养老资产、截图识别、公开部署与专业核定服务。
