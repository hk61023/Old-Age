# 抓取来源维护（1.2.0）

进入原有SSH隧道管理页，登录后选择「抓取来源」。支持按省份、分类、标题、网址搜索，新增、编辑、启停、单独检查和最近50次历史。停用保留快照与审核记录；预置清单更新不会重新启用或覆盖管理员修改。养老金政策与收入统计独立生成候选。

## 调度与安全

服务运行时每天北京时间09:00检查，漏跑后启动补查一次。任务保存在SQLite，按400页一批自动续跑，重启接续未完成部分；重复点击复用当前任务。两页并发，同一主机串行且完成后至少间隔1秒。每个目录最多3页，每页最多发现20篇相关文件；文章持续跟踪而不继续扩散。

仅接受政府HTTPS网址，逐次校验重定向、DNS所有解析地址，实际连接固定到校验过的公网地址；拒绝内网、回环、链路本地和元数据地址。正文上限2MB，网络超时15秒；附件、验证码和不可解析站点进入人工处理，不绕过验证。来源变化或首次采集只生成候选，不自动修改公式或发布参数。

## 本次来源核验

服务器实际检查149个入口及文件页，核验32个栏目候选。自动发现曾混入新闻、无关税务文件与错误地域归属，已人工剔除或纠正。最终人工复核清单19条（含5个国家栏目），9条通过本次正文解析，10条需人工处理。另保留既有31省来源、政策原文与收入来源；未核验不冒充已接入。省级来源不等于独立市级栏目覆盖，直辖市区县共用市级来源。

逐项网址、状态和发现页见 `artifacts/discovery/report.json`；该文件为原始探测记录，不是最终有效覆盖数量。采用清单为 `src/data/monitor-seed.json`，人工复核说明见 `artifacts/discovery/人工复核说明.md`。后台「全国来源覆盖与待补齐地区」展示当前缺口。许多站点从香港服务器访问超时，全国主要城市独立栏目仍未全部接入。

## 接口与数据库

`/api/admin/sources` GET查询、POST新增；`/api/admin/sources/:id` PUT编辑；`/:id/check` POST单独检查；`/:id/history` GET历史。均要求管理员会话，写操作另校验Origin及CSRF。公网Nginx继续禁止管理路径，SSH隧道使用原密码登录。

增量新增 `monitor_sources`、`monitor_tasks` 表，不替换既有政策、管理员、审核历史和收入记录。任务总数会随新发现文件增加，完成数、剩余数与失败明细可查询。失败保留已发布参数与上次成功快照。

## 验证与回滚

82项回归通过，包含405来源跨批次、停止恢复、重复点击、同站限速、3页20链接上限、附件、失败保护、候选分类隔离、登录/CSRF/危险地址、管理员修改保留和旧方案快照。隔离浏览器实例验收来源新增、编辑、启停、单独检查及历史；生产管理员密码不重设。

部署前启动 `yanglao-backup.service` 生成一致性备份，保存在 `/var/lib/yanglao/backups`。保留上一版本目录，可把 `/opt/yanglao/current` 指回旧版本并重启服务；新增表可保留，不应覆盖数据库。只有确实需要回滚数据时才停服务并从一致性备份恢复。HTTPS证书及原自动续期任务保持不变。
