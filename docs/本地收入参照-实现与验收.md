# 本地收入参照：实现与验收

核验日期：2026-10-19。模块已经加入知年本地应用的独立导航，养老金结果可直接带入预计领取地、首次领取月份和当前测算金额。

## 地区与统计资料

- 大陆31个省级地区、浙江11市、2025年GDP前100城市，去重103市（原38市增加65市）。直辖市省、市入口指向相同的全市记录，不复制为区县数据。
- 规划分组表实际列出29座城市；按规划引用的29座万亿城市加徐州的年度榜单，补入唐山，配置与覆盖测试均为30座。
- 目前505条统计记录，131个独立地区（含全国）。GDP前100城市100/100、浙江11/11、目标城市103/103均有本市居民收入指标，没有借用省值。
- 覆盖数字表示“已有本地区居民收入主指标”，不表示全体、城乡及两类工资全部核验。逐项状态见[收入资料覆盖表](收入资料覆盖表.md)；结构化验收结果在 `artifacts/income-coverage.json`。
- 工资目前123条；31个省级地区均有2024年私营及非私营工资。103座目标城市中，私营工资已核验20市、非私营31市。新增宿迁2025年两类工资，唐山、邯郸、沧州、廊坊2024年非私营工资。其余工资缺项保留待核验。嘉兴、湖州公报中的私营工资只限规模以上单位，未充作全口径私营工资；没有以社保全口径工资、在岗职工工资替代单位就业人员平均工资。
- 103座目标城市的全体居民收入已有90市、城镇100市、农村102市。惠州、漳州、菏泽、邯郸、绵阳、珠海、茂名、兰州的居民收入最新核验年度为2024，其他95市至少有一项2025年居民收入。2025版年鉴通常载2024年数据，不将书名年份当成统计年度。
- 哈尔滨2025年公报注释明确从市本级改为全市口径，保留说明；石家庄居民收入不含辛集，按原文注明。城市覆盖不等于统计范围完全相同，比较时应查看来源口径。
- 长沙目前2025年城镇及农村指标已核验，全体指标待核验；深圳目前2025年全体指标已核验，城乡分项待核验；唐山全体最新为2025年，城乡最新已核验为2024年。各卡片独立标明年度。
- 吉林全体、青海城乡、陕西农村等省级分项仍待核验。中位数只录入已有官方依据的全国2025年数据，不替代本地中位数。
- 杭州和全国已加入2024—2025年居民收入，其他地区不足两年时不生成趋势。趋势仅连接相邻年度，缺年断开。

## 来源与证据边界

大部分记录来自统计局、调查队、政府公报。官方报纸、公共图书馆刊存的原文也保留刊载页链接。成都使用此前核验的统计部门署名公报在新浪的全文转载；南昌使用南昌发布政务号发布的调查队数据；呼和浩特使用呼和浩特日报正式刊载的统计公报；兰州使用甘肃省经济研究院官网完整转载的2024年官方公报。以上采用具体刊载地址白名单，不放行相应平台的任意用户页面。后续取得统计局直链应通过候选审核替换，保留版本。

东营统计局目前通过HTTP提供公开原文，只有本次核验的具体公报地址可作为人工资料来源。自动监测仍强制HTTPS和公网DNS检查，不为此放宽抓取安全限制；该原文需要人工复查，自动抓取失败保留已发布数据。连云港PDF服务器HTTPS证书异常，已从官网公布的HTTP附件地址读取原文，正式记录保留HTTPS政府刊载页入口。

种子记录保存统计数值、口径、来源网址、发布日期（原文未标注时留空或只记月份）、核验日和核验摘录。摘录中有为表格转录的数值摘要，不把转录摘要称为完整网页原文。服务运行时，自动检查另外保存原文正文快照、内容摘要哈希与变更候选；附件标明人工提取，不自动发布。原网页无法抓取时保留已发布资料，不以失败结果清空。

## 使用方式

1. 收入参照页选择独立生活地区，可用浙江全市、GDP前30、GDP前100和搜索筛选。若养老金带入了未覆盖城市，会提示并提供“改看所在省级地区”，不会自动将省值标成本市。仅已核验城乡分项的城市会提示切换适用参照人群，不估算全体均值。
2. 个人可支配收入、家庭人均、个人税前工资分开计算。月收入方式须填写未包含在月收入中的额外年度收入，没有则填0，避免遗漏或重复奖金。家庭人数包含无收入成员。
3. 显示倍数、高低比例、年/月差额及达到参照值的差额；均值不能推导人口百分位或贫困、中产标签。
4. 横向最多比较三个地区，固定同指标、人群和共同最新年度，没有共同年度会提示。
5. 养老金历史参照明确首次领取年度与统计年度；未来增长率默认空白，主动填写后才计算名义金额情景。部分养老金只作为已测算分项参照。
6. 个人收入仅保留在组件内存，刷新清空；不会进入请求、浏览器持久存储或原养老金方案格式。

## 维护与接口

- SQLite使用新增的 `income_records`、`income_candidates`、`income_sources`、`income_snapshots` 表，与养老金资料分开。重复启动不覆盖已发布修订，回滚后新增版本继续递增。
- 公开接口：`GET /api/income-statistics`，可用 `region`、`year`、`group=zhejiang|gdp30|gdp100|required`，只返回已发布资料。不接受个人金额参数。
- 后台入口沿用 `/admin` 的现有登录，新增收入覆盖表、逐项录入及JSON批量导入、候选编辑、发布、驳回、来源维护、历史版本和回滚。写操作沿用来源校验及CSRF。
- `/api/admin/income/dashboard` 返回已发布记录、逐记录下一版本、候选、来源状态及覆盖数；其余接口为 `check`、`sources`、`candidates`、`candidates/:id`、`candidates/:id/approve`、`candidates/:id/reject`、`versions/:id`、`rollback`。
- 沿用本地服务每日北京时间09:00检查与启动补查。检查仅在服务运行期间执行，自动发现只生成候选；管理员确认后发布。栏目目录可在后台维护，当前加入全国、长三角、广州和辽宁大连入口，各原文另行跟踪修订。
- GDP前100范围集中在 `src/data/income-gdp100.json`，由 `src/data/income-regions.ts` 合并既有城市与浙江全市。名单来自2025年各地全年全行政区域GDP初核数的汇编，不称为国家统计局统一排名。每年由维护者审核完整年度榜单，新增城市并保留已收录城市，不自动按季度榜单修改。
- 运行 `node --import tsx scripts/income-audit.ts` 可重新校验种子资料并生成逐项覆盖表。
- `scripts/import-income-ledger.ts` 仅接受已人工核验的来源账本，逐项校验城市、年度、人口类型、金额及来源，拒绝覆盖已有不同金额；自动发现候选继续走后台审核发布，不使用该脚本自动发布抓取结果。

## 验收范围

自动测试覆盖计算、输入、年份、地区数量、来源地址约束、候选隔离、失败保护、登录与CSRF、发布、旧版本拒绝、回滚后版本号以及既有SQLite增量升级。原有养老金测试一并运行。浏览器在隔离内存数据库的本地3211端口检查个人/家庭/工资模式、月收入奖金、城市筛选、养老金地区带入、未来情景与390px手机布局；没有修改现有管理员账户。

百城扩展补充验收：88项测试全部通过，TypeScript检查与Vite生产构建通过；隔离3212服务检查百城筛选、绵阳2024城镇收入49666元与60000元个人收入的1.21倍参照、宿迁2025两类工资。390px手机视口检查无横向溢出，并修正收入页面第三个模式按钮被养老金页面公共样式压窄的问题。独立年度缺项不会混入同年比较。

正式本地服务使用3210端口、既有 `data/policies.sqlite`。自动发现真实网站能否长期稳定抓取取决于对方网络及栏目变化；失败会在来源状态记录，并保留旧版。上述资料缺项和特殊刊载来源仍需持续维护，不能将城市覆盖完成称为全部统计分项已经补齐。线上发布记录另见部署验收。
