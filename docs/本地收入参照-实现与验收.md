# 本地收入参照：实现与验收

核验日期：2026-10-19。模块已经加入知年本地应用的独立导航，养老金结果可直接带入预计领取地、首次领取月份和当前测算金额。

## 地区与统计资料

- 大陆31个省级地区、浙江11市、2025年GDP前30城市，去重38市。直辖市省、市入口指向相同的全市记录，不复制为区县数据。
- 规划分组表实际列出29座城市；按规划引用的29座万亿城市加徐州的年度榜单，补入唐山，配置与覆盖测试均为30座。
- 目前214条统计记录，66个独立地区（含全国）。每个必含城市都有本市居民收入指标；没有借用省值。
- 覆盖数字表示“已有本地区居民收入主指标”，不表示全体、城乡及两类工资全部核验。逐项状态见[收入资料覆盖表](收入资料覆盖表.md)；结构化验收结果在 `artifacts/income-coverage.json`。
- 工资目前13条，覆盖全国、江苏、江西、深圳、武汉、广州、常州7个地区。武汉目前仅非私营工资，其余未取得的工资分项显示“待核验”。没有以社保全口径工资、在岗职工工资替代单位就业人员平均工资。
- 长沙目前2025年城镇及农村指标已核验，全体指标待核验；深圳目前2025年全体指标已核验，城乡分项待核验；唐山全体最新为2025年，城乡最新已核验为2024年。各卡片独立标明年度。
- 吉林全体、青海城乡、陕西农村等省级分项仍待核验。中位数只录入已有官方依据的全国2025年数据，不替代本地中位数。
- 杭州和全国已加入2024—2025年居民收入，其他地区不足两年时不生成趋势。趋势仅连接相邻年度，缺年断开。

## 来源与证据边界

大部分记录来自统计局、调查队、政府公报。统计报告在官方报纸或公共图书馆刊存的原文也保留刊载页链接。少量来源需特别识别：成都为统计部门署名的《2025年成都市国民经济和社会发展统计公报》，当前链接为成都日报原刊在新浪的全文转载；这不是直接政府域名页面。服务只对这一具体转载地址单独放行，不放行新浪其他页面。后续取得统计局直链应通过候选审核替换，保留版本。

种子记录保存统计数值、口径、来源网址、发布日期（原文未标注时留空或只记月份）、核验日和核验摘录。摘录中有为表格转录的数值摘要，不把转录摘要称为完整网页原文。服务运行时，自动检查另外保存原文正文快照、内容摘要哈希与变更候选；附件标明人工提取，不自动发布。原网页无法抓取时保留已发布资料，不以失败结果清空。

## 使用方式

1. 收入参照页选择独立生活地区，可用浙江全市、GDP前30和搜索筛选。若养老金带入了未覆盖城市，会提示并提供“改看所在省级地区”，不会自动将省值标成本市。
2. 个人可支配收入、家庭人均、个人税前工资分开计算。月收入方式须填写未包含在月收入中的额外年度收入，没有则填0，避免遗漏或重复奖金。家庭人数包含无收入成员。
3. 显示倍数、高低比例、年/月差额及达到参照值的差额；均值不能推导人口百分位或贫困、中产标签。
4. 横向最多比较三个地区，固定同指标、人群和共同最新年度，没有共同年度会提示。
5. 养老金历史参照明确首次领取年度与统计年度；未来增长率默认空白，主动填写后才计算名义金额情景。部分养老金只作为已测算分项参照。
6. 个人收入仅保留在组件内存，刷新清空；不会进入请求、浏览器持久存储或原养老金方案格式。

## 维护与接口

- SQLite使用新增的 `income_records`、`income_candidates`、`income_sources`、`income_snapshots` 表，与养老金资料分开。重复启动不覆盖已发布修订，回滚后新增版本继续递增。
- 公开接口：`GET /api/income-statistics`，可用 `region`、`year`、`group=zhejiang|gdp30|required`，只返回已发布资料。不接受个人金额参数。
- 后台入口沿用 `/admin` 的现有登录，新增收入覆盖表、逐项录入及JSON批量导入、候选编辑、发布、驳回、来源维护、历史版本和回滚。写操作沿用来源校验及CSRF。
- `/api/admin/income/dashboard` 返回已发布记录、逐记录下一版本、候选、来源状态及覆盖数；其余接口为 `check`、`sources`、`candidates`、`candidates/:id`、`candidates/:id/approve`、`candidates/:id/reject`、`versions/:id`、`rollback`。
- 沿用本地服务每日北京时间09:00检查与启动补查。检查仅在服务运行期间执行，自动发现只生成候选；管理员确认后发布。栏目目录可在后台维护，当前加入全国、长三角、广州和辽宁大连入口，各原文另行跟踪修订。
- GDP范围集中在 `src/data/income-regions.ts`。每年由维护者审核完整年度榜单，新增城市并保留已收录城市，不自动按季度榜单修改。
- 运行 `node --import tsx scripts/income-audit.ts` 可重新校验种子资料并生成逐项覆盖表。

## 验收范围

自动测试覆盖计算、输入、年份、地区数量、来源地址约束、候选隔离、失败保护、登录与CSRF、发布、旧版本拒绝、回滚后版本号以及既有SQLite增量升级。原有养老金测试一并运行。浏览器在隔离内存数据库的本地3211端口检查个人/家庭/工资模式、月收入奖金、城市筛选、养老金地区带入、未来情景与390px手机布局；没有修改现有管理员账户。

正式本地服务使用3210端口、既有 `data/policies.sqlite`。自动发现真实网站能否长期稳定抓取取决于对方网络及栏目变化；失败会在来源状态记录，并保留旧版。上述资料缺项和成都来源刊载方式仍需持续维护，不能将本次功能验收称为全部统计分项已经补齐。没有进行远程部署。
