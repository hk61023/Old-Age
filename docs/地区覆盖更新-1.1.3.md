# 地区覆盖更新 1.1.3

核验日期：2026-10-13。

测算下拉可选16个省级地区、215个城市或区县。全国31省451条目录仍用于政策查询、历史参保记录和CSV校验。未覆盖省份与菏泽隐藏；保存方案若原选地区不再可选，保留原输入并显示禁用提示，不自动换成其他地区。

已发布地方公式优先。其他有官方计发基数的地区仅使用国发〔2005〕38号计算基础与个人账户参考分项，状态永远为部分结果。完整金额、过渡性和地方项目保留未知。指数分母缺失时明确采用指数1的平均缴费水平情景，计发基数不当作指数分母；有视同缴费且口径未知时不输出基础分项。未来适用缴费上下限缺失时，按所填水平推算并注明未校验合法档次。

天津手算样例：2025年度计发基数9417元，缴费240个月、指数1，实际账户139000元、计发月数139，无未来缴费，基础1883.40＋账户1000＝参考合计2883.40元。完整待遇仍未知。实际余额不重复累计历史缴费；旧余额后续记录不完整时不合计。

上述参数均保留2025所属年度；沿用预测明确标注，不声称2026年最新参数已全面公布。增量参考更新脚本先备份数据库，只补已人工核对参数，保留已发布政策与管理员设置，写入审计。新增保存方案包含参考参数快照，旧方案显示原结果，主动重算才采用当前数据。

验证结果：57项测试通过；TypeScript及生产构建通过。全国451条目录×8＝3608组测算无异常。基础示例中完整情景33条、通用公式部分合计151条、浙江省级部分合计10条、广东仅分项21条；其余236条不出金额且从测算下拉隐藏。16个可选省份逐一在浏览器切换，均显示分项；山东不含菏泽。页面证据见artifacts/selectable-provinces.jpg，逐省记录见selectable-provinces-browser.json。

当前仍未达到全国31省金额覆盖，缺少必要官方计发参数的15省保留查询，暂不进入测算选项。
