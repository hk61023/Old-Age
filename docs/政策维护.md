# 政策维护与本机数据

## 管理员设置与安全范围

在本机打开 `/admin`，自行输入并确认至少12位管理密码。数据库保存随机盐和scrypt摘要，不保存明文。会话8小时，HttpOnly及SameSite=Strict；写操作校验Origin和CSRF。服务固定监听127.0.0.1，Host仅允许localhost/127.0.0.1，没有公开部署入口。

无默认管理密码。本轮实际管理页面验收使用3211端口的独立内存数据库，正式3210数据库没有被写入测试密码或测试发布版本。测试服务停止后其管理密码和候选一并消失。

## 更新检查与人工发布

服务运行期间每分钟检查是否到北京时间09:00。每日只自动检查一次；关闭电脑期间不工作，启动发现错过日期后补查一次。按钮“立即检查官方更新”可主动重查，同一来源同一正文哈希不会重复生成候选。

1. 打开管理页，查看检查任务及失败来源。首次抓取也会进入候选，需与种子基线核对。
2. 打开官方原文，核对文号、发布及适用日期、参数年度、人群与地区。目录仅发现文件，不表示目录数字可直接用于计算；PDF等附件进入人工提取。
3. 选择候选，载入对应政策模板；填写结构化参数和至少10字核验说明。需要新增年度政策时可在候选模板中使用新id；修改已有版本沿用id并递增version。
4. 用独立手算填写样例的expectedBasic、expectedAccount，至少1例、最多20例。可从 `docs/政策基线.md` 的固定样例开始；变更公式还必须修改TypeScript并运行全套测试，不能在JSON中输入执行代码。
5. 保存候选并运行样例，页面展示预期与实际。只有通过后才允许点击发布，服务器发布时再次校验，防止绕过按钮或沿用失效候选。
6. 发布写入不可覆盖的历史版本和审核记录。候选驳回不影响现行版。选择“历史与回滚”可恢复该id原版本，之后再次修订使用历史最大版本+1。

只支持已适配的地区/公式组合。新增其他省份公式需代码适配、来源核对和测试后开放；不得改地区代码去套用其他省公式。公共API返回各年度政策包，浏览器按适用年月选择。按日切换的月份会要求核实，避免月份精度直接决定适用规则。

**审核仍需人判断完整性。** 默认样例检查基础和账户两项，并不能证明所有过渡性/地方待遇已核验，需另外运行项目专项回归。资料不齐时保留limitations和部分结果。未发布候选不生效，自动发现也不会改变核验时间。

## 抓取失败与变化差异

仅访问HTTPS政府站点，重定向同样校验；15秒超时、正文上限2MB、并发2、每次最多80页。抓取文本与原正文并列显示供人工比较，不产生可执行公式。来源返回验证页面、TLS错误、超时、正文不完整或附件无法解析均进入任务错误/人工处理。

当前环境中部分政府站点能在浏览器打开，但Node自动抓取失败。不要关闭TLS校验；保留旧版，打开原文人工核对后新建修订候选。检查任务成功只表示取得正文，**不代表政策已经审核发布**。

## 备份

网站启动后运行：

```powershell
cd C:\codex\yanglao
npm run backup
```

使用SQLite `VACUUM INTO` 生成一致性备份，位于 `data/backups/policies-时间.sqlite`，可在服务运行时执行。不要直接复制运行中的主数据库文件来替代一致性备份。备份含政策、原文快照、候选、管理员摘要及审核记录，不含浏览器个人方案；浏览器方案请在“我的方案”导出JSON。

## 恢复

先在启动终端按Ctrl+C停止服务，再恢复。保留原数据库、WAL和SHM文件便于撤回。以下例子需要把第一行换成实际备份路径；所有移动在同一PowerShell中完成，只移动明确命名的本项目文件，不递归删除目录。

```powershell
$yanglaoBackup = 'C:\codex\yanglao\data\backups\policies-实际时间.sqlite'
$yanglaoData = [IO.Path]::GetFullPath('C:\codex\yanglao\data')
if (!(Test-Path -LiteralPath $yanglaoBackup -PathType Leaf)) { throw '备份不存在' }
$yanglaoRecovery = Join-Path $yanglaoData ('before-restore-' + (Get-Date -Format yyyyMMdd-HHmmss))
New-Item -ItemType Directory -Path $yanglaoRecovery | Out-Null
foreach ($yanglaoFileName in @('policies.sqlite','policies.sqlite-wal','policies.sqlite-shm')) {
  $yanglaoFile = Join-Path $yanglaoData $yanglaoFileName
  if (Test-Path -LiteralPath $yanglaoFile) { Move-Item -LiteralPath $yanglaoFile -Destination $yanglaoRecovery }
}
Copy-Item -LiteralPath $yanglaoBackup -Destination (Join-Path $yanglaoData 'policies.sqlite')
npm start
```

启动后检查政策数量、版本及管理员登录。恢复也会恢复备份时的管理密码摘要。需要撤销恢复时再次停止服务，用保存的 `before-restore-时间` 文件按相同方式恢复，不混用不同快照的WAL。不要恢复未经信任来源提供的数据库。

## 个人方案删除与旧方案

“我的方案”逐项删除只操作当前浏览器localStorage；未保存填写离开页面就丢失。浏览器站点数据清除可一次清空所有方案。查看旧方案直接使用保存结果及快照；主动按当前发布政策重算才调用当前引擎重新计算。导出JSON用于留档，首版没有任意JSON回导功能。

在3210和localhost、不同浏览器或不同端口保存的资料属于不同站点存储，不能自动互见。管理员政策备份不会自动备份或上传这些个人资料。
