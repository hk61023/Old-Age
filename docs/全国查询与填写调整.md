# 1.1.0 全国查询与填写调整

2026-10-13实施。网站继续只在127.0.0.1运行，个人资料不传到后端。

## 填写与退休年龄

- 实际缴费时间使用单一“累计实际缴费月数”，不再输入年与剩余月。与视同缴费月份分开。
- 基础信息、必需的情景参数以及填写余额后必需的日期都有红色星号。可留空的本人官方指数、账户金额没有强制预填。
- 全国延迟退休由出生年月和原退休类别计算；原60岁及55岁类别每4个出生月份增加1个月，原50岁类别每2个出生月份增加1个月，分别最多延迟36、36、60个月。金额输入无效时仍显示已确认的法定退休年龄分解。
- 依据：[全国渐进式延迟退休决定与官方说明](https://www.gov.cn/zhengce/202409/content_6974508.htm)。弹性退休提前/延后月数单独计算。

## 账户余额与个人指数

账户余额改称“个人账户累计储存额（元）”，包含已记账利息，以养老保险权益单的实际统计截止月为准。上年末对应上年12月；本年实际值对应已出具权益记录的月份。2026年10月资料不会提供2026年12月实际余额快捷项。旧余额后缺缴费记录会保留金额缺口，不假定后续已经缴费。

“本人官方平均缴费指数”是个人记录的计算或核定结果，需要历年个人缴费工资和对应年度地区工资口径，不能作为城市人口共享参数。依据：[河南人社对平均缴费工资指数的说明](https://hrss.henan.gov.cn/2014/12-25/1576313.html)。地区工资分母、缴费上限、养老金计发基数是三个不同数据。

表单根据“当前参保地区”自动展示已核验的指数参考工资（分母）、年度和链接。尚未核验的年度不自动生成个人官方指数；旧年度值明确为历史查询，不直接充当2026年当前值。既有完整记录指数测算仍受当地口径和对应年度分母完整性约束。

## 全国查询覆盖

公共地区目录含内地31个省级地区及451个城市、直辖市区县或省直辖分类条目，可按省份、城市及名称搜索。主要城市包含在该目录内。目录不是当前行政区划新旧变更的法律核定凭据；特殊范围须单独处理。

31个省级人社官方入口来自[人社部中国就业网地方链接](https://chinajob.mohrss.gov.cn/zcms/catalog/32/pc/index_402.shtml)。已收录部分官方数值的省级地区共20个：北京、天津、山西、内蒙古、辽宁、吉林、上海、江苏、浙江、安徽、福建、江西、山东、湖北、湖南、广东、四川、云南、西藏、甘肃。

其余河北、黑龙江、河南、广西、海南、重庆、贵州、陕西、青海、宁夏、新疆提供官方入口，必要数值仍待逐项核验。部分地区只有缴费上下限，不能据此声称养老金计发规则、指数或当年计发基数齐全。2025年历史数值不被标成2026年最新数值。

城市差异：长春单列2025年95739元/年（月展示7978.25元），吉林其他普通范围87865元/年；农垦企业不适用普通范围。辽宁2025年7346元省级计发基数排除沈阳、大连，两市没有核验值时不套用省值。深圳单列11293元2025计发基数。原文来源和适用例外随每项参数保存。

新增参考目录不会自动启用未经适配的地区金额公式。北京、上海、广东、浙江的金额测算仍使用原已发布政策及限定范围，其他范围缺必要政策时保留不出总额。完整全国金额测算需要各省规则、地方项目、历史口径和回归样例进一步接入。

## 数据与维护

新建SQLite表regional_references，按省级代码保存经人工核对的目录与参考参数；初始化使用INSERT OR IGNORE，保留既有记录和已发布政策。公共只读接口为GET /api/regional-references，未新增接收个人资料的接口。已有已发布政策中的四地参数动态加入查询响应，避免参考目录覆盖计算政策。

参考数值包含用途、数值、参数年度、适用区间、原文链接、文号、原文发布日期；省级记录保留核验日期、适用提醒和城市例外。初始数值在src/data/regions.ts，查询及排除逻辑在src/core/regions.ts。引用的新增官方来源纳入每日09:00检查；变化仍只进入候选，不自动修改公开金额或执行原文公式。

本轮全国参考数据为人工核对的首版目录，未提供对新增省份的完整公式发布适配。新的参考条目更新需先复核原文，再通过代码和数据库版本维护，不能把待审核抓取候选直接当作已发布数值。已有四地计算政策继续使用管理员候选、回归和审核发布流程。
