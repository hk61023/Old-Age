# 1.3.0 全国城市基础测算覆盖

2026-10-19 核对：此前31省级地区共438个可选城市/区县，现补入石河子、阿拉尔、图木舒克、五家渠、北屯、铁门关、双河、可克达拉、昆玉、胡杨河、新星、白杨12市，达到450项。全国现行地级目录全部包含，涵盖省会与各省经济规模靠前城市；地级地区不足10个的省区覆盖全部，直辖市按现行区县选择。此目录不是GDP排序表。

重庆江北区、渝北区两个历史代码仅保留给历史缴费记录，不计入当前可选数量。全国查询/历史目录仍有452项。

## 计算与依据边界

- 已有地方公式和计发参数保持原有版本；没有过渡性养老金、地方待遇或当地取整资料，不阻断有效普通案例的基础与个人账户分项合计。缺项保持未知，合计标为部分结果。
- 新增兵团城市使用**区域工资参考情景**：暂用新疆官方2026缴费文件公布的2025全口径月工资8744元作为比较输入；这不是兵团正式计发基数，也不是兵团平均工资或个人指数。该借用假设在结果卡上直接展示，不作为政策发布。
- 兵团城市独立隔离自治区缴费上下限和指数参数，不自动把5246/26231元当作兵团征缴标准。未来缴费、账户入账仅按普通职工/灵活就业情景估算；连队职工、特殊退休和机关事业单位不在支持范围。
- 参考资料：[新疆官方缴费文件](https://rst.xinjiang.gov.cn/xjrst/c112734/202609/234e01d8b8b9404ca3c98c2cee384903.shtml)、[兵团企业职工待遇办理说明](https://www.xjbt.gov.cn/c/2018-07-16/8041214.shtml)、[兵团独立实施口径说明](https://www.xinjiang.gov.cn/xinjiang/c112543/202311/f1560797b2c7442a8b975c2cadcda6ee.shtml)。未用既有退休人员年度调增通知冒充新退休人员计发基数。

## 界面与迁移

政策资料库新增逐省基础测算覆盖清单，展示地方公式、通用参考和工资情景数量，可展开城市并一键进入测算。修正原先把27省标为“金额待接入”的过时说明。

现有数据库启动时仅补入新疆缺失的12市，增加参数隔离信息和审核日志；保留已有城市修订、管理员、已发布政策、收入记录和浏览器旧方案。迁移标记确保只执行一次。

## 验证

独立源码副本87项测试通过；450个可选地区的企业/灵活就业普通案例均有基础、账户及分项合计。运行中公共API另完成3616组测算（含2个历史代码的16组不适用情形），可选城市对应3600组全部可计算、程序异常0。合成案例不代表当地所有人员都已核验。

本轮与同目录正在进行的收入GDP100扩展隔离；发行包基于已提交版本5b0daa7，仅叠加养老金城市更新，不回退或覆盖未提交的收入工作。生产部署前备份，保留HTTPS、续期和公网管理隔离配置。
